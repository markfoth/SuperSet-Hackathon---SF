# Household decision workspace

The journey is destinations, priorities, suitable areas, comparison, then an actual home. The map stays available and earlier choices remain editable. Existing household, sharing and home components are reused.

Starting checkout: `efbfad1`. Live older release: `e2b6fcc`. Actual live inspection and original Git source confirm useful deep teal, practical text and direct labels. The original also exposes seven preferences immediately and enters pin mode without search. Those issues are not restored.

## Deliberate decisions

No blocking wizard, silent viewport filtering or routine input-driven camera fitting was added. Manual pan does not change recommendation scope. Analysis remains SF to SFO while map context extends further.

There is no universal liveability score. Explicit ordered measurement bands remain the model. Neighbourhoods use leading eligible representative locations; homes use actual pins for all commute gates. Shortest measured household travel and Most balanced measured commutes are conditional Homes views. Excluded, stale and incompletely measured homes cannot win. Weekly return travel remains illustrative, doubling the measured inbound journey and entered days.

Recovery counts real failed conditions, acknowledging overlaps, and evaluates changes before Apply. Offline examples offer only actual next15-minute contours; proxy mode supports five/ten-minute requests. No contour interpolation is invented. Undo restores pre-adjustment settings; manual priority/commute edits and scenario loads clear obsolete undo state.

The explorer groups food, health, libraries, exercise, markets, green-space centres and mapped entrances. Straight-line proximity is explicit. Muni counts are dated schedules, not reliability. Hazard context is outside ranking. Dates/resolution expand on demand; essential unknowns remain visible.
